# CLAUDE.md（またはカスタム指示）に追記するスニペット

下の ```markdown ブロックの中身をそのままコピーして、あなたの常時読み込みファイルに貼り付けてください。

| ツール | 貼り付け先 |
|---|---|
| Claude Code / Cowork | `CLAUDE.md` |
| Codex / GitHub Copilot CLI など | `AGENTS.md` |
| Cursor | `.cursor/rules/library.mdc` |
| ChatGPT・Gemini など | カスタム指示欄 |

```markdown
## 📚 大図書館（作業コンテキストの書庫）

**安全** — APIキー、トークン、パスワード、Cookie/セッション、`.env`/認証ファイルの中身、金融情報、住所・電話・メール、顧客の非公開情報、生ログは記録しない。値を書かず「移した」「設定した」とだけ記録する。

**読む** — 過去の経緯や決めた理由が要る仕事・同じプロジェクトの続き・提案や企画のときだけ `library/目録.md` を見て、関係する棚を1〜2冊だけ開く。棚は全文読まず、検索（Grep）で見出しやキーワードを引いて必要な部分だけ読む。単発の質問やその場で終わる作業では開かない。

**書く** — ファイルを作った・変えた作業が一区切りついたら `library/日誌/YYYY-MM.md` に5行以内で追記する。見出しは必ず
`## YYYY-MM-DD やったこと ｜棚:棚の名前`
の形にする（`｜棚:` が無いと整理されず、永久に棚へ上がらない）。棚の名前は `library/目録.md` の表にあるものを使う。

**整理** — 日誌に追記する前に、その月の日誌の見出し行だけを検索する（`^## ` で検索。本文は読まない）。`✅` の付いていない見出しが**5件以上**あれば、`library/運用ルール.md` の「4. 整理の手順」に従って棚へ転記し、済んだ見出しに `✅` を付ける。**ユーザーに頼まれなくても自分でやる。**
```

## これで何が起きるか

- 新しい会話のたびに、AIは自分で目録を見に行き、必要な棚だけ読みます
- 作業が終わるたびに日誌が1件ずつ増えます
- 5件たまった時点で、**AIが勝手に棚へ整理します**。あなたが「整理して」と言う必要はありません

`✅` は「棚に転記済み」の印です。これがあるおかげで、AIは毎回日誌を全部読み直さずに済み、同じ内容を二度転記することもありません。
