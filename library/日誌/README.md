# 日誌の書き方

日誌は「今月あったことの生の記録」を置く場所。月ごとに `日誌/YYYY-MM.md` を作り、作業が一区切りつくたびに末尾へ追記する。
正本は `../運用ルール.md` の「1. 日誌の書き方」「2. 転記マーク」。ここでは型だけ再掲する。

## 型（5行以内厳守）

```
## 2026-08-05 〇〇の作業 ｜棚:仕事
- やったこと: 何をしたか一言で
- 成果物: ファイルの場所やURL
- 学び: 次に活かせる気づき
```

- **`｜棚:` を必ず付ける。** これが無いと整理で拾えず、永久に棚へ上がらない
- 棚名は `../目録.md` の「棚の案内」表にあるものを使う（ファイル名から `.md` を取ったもの）
- 転記が済むと、AIが見出しに `✅` を付ける → `## ✅2026-08-05 ...`
- 生ログ（会話全文やエラー全文）は書かない。要点だけ
- 雑談だけのセッション・記録するほどでもない作業は書かなくてよい
- 過去の月のファイルは消さない

## 記入例

> このファイルは `20*.md` ではないので、整理の対象外です（下のサンプルが未転記として拾われることはありません）。

```
## ✅2026-08-05 サイトAのデザイン確定 ｜棚:仕事
- やったこと: クライアントとデザイン案を確定させた
- 成果物: `projects/サイトA/デザイン確定版.pdf`
- 学び: 配色は最初に希望色を聞いておくと手戻りが減る

## 2026-08-06 短編小説の第2話プロット ｜棚:趣味・創作
- やったこと: 第2話のプロットを3案出して1案に絞った
- 成果物: `creative/短編〇〇/第2話プロット.md`
- 学び: 3案出してから選ぶと、後で「他の道もあった」と迷わない
```

上は転記済み（`✅` 付き）、下はまだ未転記。整理は下だけを処理します。
