# 📚 大図書館 目録（ここだけ読めば棚がわかる案内板）

AIとの全作業のコンテキストを保管する図書館。**開くのは必要なときだけ。**

## 開く / 開かない

| 開く | 開かない |
|---|---|
| 前回どうしたか・なぜそう決めたかが要る仕事 | その場で完結する単発の質問 |
| 同じプロジェクトの続き | 一般知識で答えられること |
| 企画・提案・優先度づけ（好みの棚） | 手順が確定している定型作業 |

迷ったら開かない。必要になった時点で開けば足りる。

## 使い方（3行）

1. この目録を見て、関係する棚を1〜2冊だけ選ぶ
2. 棚は全文読まない。検索（Grep）で見出しやキーワードを引き、該当セクションだけ読む
3. 作業が一区切りついたら `日誌/YYYY-MM.md` に5行以内で記録する
   → 見出しに `｜棚:◯◯` を必ず付ける（これが無いと棚へ上がらない。書き方は `運用ルール.md`）

## 棚の案内

| 棚 | こういう仕事のときに開く |
|---|---|
| [仕事](棚/仕事.md) | 本業・副業・案件の経緯や決定事項 |
| [趣味・創作](棚/趣味・創作.md) | 個人的な創作物・趣味のプロジェクト |
| [AI活用術](棚/AI活用術.md) | AIの使い方の工夫・コスト管理・過去の失敗と対策 |
| [自分の好み・判断基準](棚/自分の好み・判断基準.md) | 企画提案・デザイン判断・優先度づけの前に開く |

> **導入直後の注意（AIへ）**: 棚の中身がサンプルのままのときは、それを利用者の事実として扱わないこと。
> サンプル区切りより下は例示であって、本人の情報ではない。

## 整理はAIが自分でやる

日誌に追記する直前に、その月の見出し行だけを検索し、`✅` の無い見出しが**5件以上**あれば棚へ転記する。
手順は `運用ルール.md` の「4. 整理の手順」。**ユーザーが「整理して」と言う必要はない。**

## 他の置き場との役割分担（重複させない）

| 置き場 | 何を置くか | いつ読まれるか |
|---|---|---|
| **CLAUDE.md / AGENTS.md** | 絶対ルール（毎回の判断を変えるものだけ） | 毎回自動 |
| **library/棚** | やり方の知見・決定の理由・経緯。ルール未満だが後で効く知識 | 必要なときだけ |
| **library/日誌** | 時系列の生の記録（棚に上がるまでの待合室） | 整理のときだけ |

同じ内容を2箇所に書かない。詳しい原本がある方にだけ書き、他方からはリンクする。

## 棚の増やし方

- 新しいテーマの作業が2〜3回続いたら、専用の棚を1つ作る（`棚/◯◯.md`）
- **この表に1行追記する**（整理はこの表を見て転記先を決めるため、追記しないと転記されない）
- 棚が300行を超えたら内容ごとに分割し、目録も更新する

## 日誌・年鑑

- `日誌/YYYY-MM.md` ← 今月の記録。月ごとに1ファイル。転記済みの見出しには `✅` が付く
- `年鑑/YYYY.md` ← 慣れてきたら年1回、その年の日誌12ヶ月分を1ページに凝縮する（最初は無くてよい）
