# 図書館を整理する

`library/運用ルール.md` の「4. 整理の手順」を実行する。**トークン最小で回すこと。**

1. 検索（Grep）で `library/日誌/` の **`20*.md` だけ**を対象に `^## ` 行を取得する（`README.md` は対象外。本文は読まない）
2. `✅` が付いていない見出しが対象。0件なら「未転記なし」と1行だけ報告して**即終了**
3. 対象エントリの数行だけを読み、見出しの `｜棚:` が指す棚へ転記・統合する
   - APIキー・トークン・パスワード・個人情報・生ログなどの禁止情報を見つけたエントリは棚へ転記しない。値を表示せず利用者へ報告し、資格情報なら無効化・再発行を優先する
   - 転記先は `library/目録.md` の「棚の案内」表が正。棚を勝手に増やさない
   - `｜棚:` の指定が無いものは内容から判断し、報告で「指定漏れ◯件」と伝える
   - 既存エントリと重複する内容は統合する
4. 開いた棚に今の事実と矛盾する古い記述があれば直す・消す（開いていない棚は見に行かない）
5. 転記できたエントリの見出しの日付の前に `✅` を付ける（`## ✅YYYY-MM-DD ...`）。本文は消さない
6. 「転記◯件、改訂◯件、指定漏れ◯件」を1〜2行で報告する

## やらないこと
- 全巻の読み返し・棚の全文読み込み
- 日誌本文の削除や要約し直し
- 棚が300行を超えていない限りの分冊（超えたら分冊し目録も更新する）
