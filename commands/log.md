# 日誌に記録する

`library/運用ルール.md` の「1. 日誌の書き方」に従って、直前までの作業を記録する。

1. 今月の日誌 `library/日誌/YYYY-MM.md` を用意する（無ければ新規作成し `# 日誌 YYYY-MM` を先頭に書く）
2. **追記する前に整理判定**：その月の見出し行だけを検索し（`^## `）、`✅` の無い見出しが5件以上あれば
   `library/運用ルール.md` の「4. 整理の手順」を先に実行する
3. 今回の作業を5行以内で末尾に追記する

```
## 2026-08-05 やったこと ｜棚:棚の名前
- やったこと: 何をしたか一言で
- 成果物: ファイルの場所やURL
- 学び: 次に活かせる気づき
```

- `｜棚:` は必須。棚名は `library/目録.md` の表にあるものを使う
- 生ログは書かない。5行を超えない
- 記録する価値がない作業なら「記録するほどのことはしていません」と伝えて書かない

最後に、書いた見出し1行だけを報告する。
